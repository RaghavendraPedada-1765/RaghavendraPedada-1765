## Hi, I'm Raghavendra

I'm a **final-year B.Tech Computer Science and Engineering student** at **Alva's Institute of Engineering and Technology (VTU)**, specializing in **IoT, Cybersecurity and Blockchain** (graduating **2027**), and a **Software Intern at IFB Automotive**.

I work on two tracks: **IoT and embedded systems**, and **AI and software development**. My core strength is **edge AI**: models that run on the device, with no cloud dependency, so data stays private and systems keep working offline. I've shipped software on Windows desktop (C#/.NET), Android (Flutter), the web (React, FastAPI) and Raspberry Pi, with automated tests and CI/CD.

- **Currently:** Software Intern at IFB Automotive, and reproducing the [NeuEdge](https://arxiv.org/abs/2602.02439) spiking-neural-network paper in PyTorch.
- **Research:** co-author of an IEEE conference paper on the Edge-AI Smart Mirror, submitted to ICIPCN 2027 (under review).
- **Based in:** Bengaluru / Mangaluru, India.
- **Open to:** internships and collaboration in IoT, embedded systems, edge AI and software engineering.
